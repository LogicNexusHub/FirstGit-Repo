# FirstGit-Repo
Practice Git commands
git clone <URL>          # Copy/download a GitHub repository to your local machine <br/>
git status               # Check the status of files (new, modified, deleted) <br/>
git add <file-name>      # Add a specific file to the staging area <br/>
git add .                # Add all changed files to the staging area <br/>
git commit -m "message"  # Save staged changes to your local repository with a message <br/>
git push origin main     # Upload local commits to the main branch on GitHub <br/>
git pull origin main     # Download and merge latest changes from GitHub <br/>
git branch               # Show all local branches <br/>
git checkout <branch>    # Switch to another branch <br/>
git checkout -b <branch> # Create and switch to a new branch <br/>
git merge <branch>       # Merge a branch into the current branch <br/>
git log                  # View commit history <br/>
git diff                 # View changes before committing <br/>
